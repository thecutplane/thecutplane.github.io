# CUTPLANE fact checks

Public fact-check pages for the CUTPLANE YouTube channel, served at https://thecutplane.github.io/.

Rules (approved by the channel editor, 23/11/2026):
- Every episode has its own folder (`epNN-slug/index.html`) and its own ledger (`ledgers/epNN-slug.json`).
- After a video is published, its folder is **never overwritten**. A correction is added as a dated note on that page only.
- A new episode only adds a new folder and one new line to the home page list (`index.html`).
